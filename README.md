## About

I am building a practical foundation in software, embedded systems, and computational biology. I enjoy taking a project from an experiment to a documented, reproducible implementation—with clear attribution when I learn from open-source work.

## Current interests

- **Embedded systems:** ESP32, Arduino, OLED displays, sensors, and serial interfaces
- **Computer architecture:** FPGA-based digital design and custom RISC-V processors
- **Hardware security:** exploring cryptographic accelerators and verifiable hardware experiments
- **Bioinformatics:** Python-based sequence analysis and reproducible data workflows
- **Software:** Python, SQL, Java, C++, Git, and technical documentation

## Featured work

### [boredphoenix-](https://github.com/nonchalantphoenix/boredphoenix-)

An embedded-systems learning repository featuring an attributed ESP32 OLED Video Converter project. The project converts video frames into monochrome data for 128×64 SSD1306 and SH1106 OLED displays.

[View the ESP32 OLED project →](https://github.com/nonchalantphoenix/boredphoenix-/tree/main/ESP32-OLED-Video-Converter)

## Learning roadmap

1. Build and verify small ESP32 and Arduino systems.
2. Develop RTL fundamentals with simulation and testbenches.
3. Implement a compact RV32I-compatible processor on FPGA.
4. Explore hardware cryptography through testable, documented accelerators.
5. Apply Python and SQL to reproducible bioinformatics workflows.

## Engineering principles

- Document assumptions, setup steps, and limitations.
- Test hardware and software separately before integrating them.
- Credit original authors and preserve license information.
- Prefer small, reproducible experiments over unsupported claims.
